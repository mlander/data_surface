Every door reads one surface

Every door reads the one sealed data surface and nothing else: the form, the tool and through it MCP and ECA, HTTP with its OpenAPI document and through it the React page. The same values sent through any door give one accepted document and one refusal list, by pointer and code, because nothing an operation runs reads the request; and no schema a door advertises is stricter than what the pipeline accepts.
