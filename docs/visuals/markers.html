The four markers

A marker on a key in the full schema says how far that key can be trusted and what a client does about the rest. enumerated is stated in full, deferred is fetched once per choice, refine is asked again with values, and live is asked on every request; checkedOnServer names a constraint only the server checks. In contract 4, deferred is an object holding its fetch template, and live also marks a key a runtime access answer may lock or leave out.
