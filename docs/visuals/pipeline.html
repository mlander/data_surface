What a key goes through

Every door hands its values to one pipeline: accept() coerces and merges them, validate() refines the keys for those values and then checks them, prepare() rehearses the write, and commit() makes it. Only commit has side effects, so a dry run is the pipeline stopped before it; a computed key is filled at the end of accept, from what its sources were accepted as.
