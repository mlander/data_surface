Six ways to compose

A resource or structure is made of others in six ways, and each keeps the keys in a different place. Nest for a thing of its own, mix in for shared members that are part of this thing, and read a port for a value the container holds. Use variants when a key chooses the keys, a collection when groups repeat, and keys from the site when the site, not the code, decides how many there are.
