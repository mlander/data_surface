# Adopter sandbox modules

Sandbox modules written to measure the pattern against a settings form we
did not write. They are not part of the module and are not shipped with it.

- `ds_adopter_pathauto_two`: the second port of Pathauto's settings form,
  2026-10-26, logged in `docs/adopters-2026-10-26.md`. Installs beside
  Pathauto on a site that has data_surface, and writes its own config
  object, `ds_adopter_pathauto_two.settings`.
